# treescape gallery

Eight feature variants on a single 12-tip primate phylogeny, plus two combinations. All SVGs are regenerated by `scripts/regen_assets.py` from the same Newick fixture (`tests/fixtures/trees/medium/primates.nwk`) and the same synthetic metadata (clade taxonomy + bootstrap-style support, defined inline in the script).

| File | Feature | Code |
|---|---|---|
| [`01_rectangular.svg`](01_rectangular.svg) | Rectangular layout (v0.1 baseline) | `TreePlot(...).options(...)` |
| [`02_circular.svg`](02_circular.svg) | Circular layout (v0.2) | `.layout("circular")` |
| [`03_rectangular_highlight.svg`](03_rectangular_highlight.svg) | Clade highlight, rectangular (v0.2 styling) | `.highlight_clade(GREAT_APES, color="#ffb84d", alpha=0.35)` |
| [`04_circular_highlight.svg`](04_circular_highlight.svg) | Clade highlight, circular — **annular sector** (v0.3 Phase 3) | `.layout("circular").highlight_clade(...)` |
| [`05_color_tips_by_clade.svg`](05_color_tips_by_clade.svg) | Discrete tip color via Tableau-10 (v0.3 Phase 2) | `.join_metadata(df, on="tip").color_tips_by("clade")` |
| [`06_color_branches_by_clade.svg`](06_color_branches_by_clade.svg) | Discrete branch color, monophyly-only (v0.3 Phase 2) | `.color_branches_by("clade")` |
| [`07_color_tips_by_support.svg`](07_color_tips_by_support.svg) | Continuous tip color via viridis (v0.3 Phase 2) | `.color_tips_by("support")` |
| [`08_color_branches_by_support.svg`](08_color_branches_by_support.svg) | Continuous branch color, subtree mean (v0.3 Phase 2) | `.color_branches_by("support")` |
| [`09_scale_bar.svg`](09_scale_bar.svg) | Branch-length scale bar (v0.3 bonus) | `.scale_bar(0.05, "0.05 substitutions/site")` |
| [`10_combined.svg`](10_combined.svg) | Highlight + discrete tip color + scale bar (publication-style) | several methods chained |

## Notes worth knowing

- **Same options across the gallery.** All rectangular renders use `padding=16, px_per_x=1200, px_per_y=24, font_size=12`; all circular renders use `padding=16, px_per_x=900, font_size=12`. Compare features apples-to-apples without dimension drift between examples.
- **Discrete branch coloring** (`06_color_branches_by_clade.svg`) leaves *paraphyletic* MRCA branches at the default color and emits a `TreescapeStyleWarning` per such branch. Visible in the SVG as default-stroke branches connecting differently colored monophyletic subtrees. The regen script silences these warnings during gallery rendering — they're informational, not errors.
- **Continuous coloring** uses treescape's pinned 11-keystop viridis LUT (see `docs/conventions.md`). Endpoints are `#440154` at `t=0` and `#fde725` at `t=1`. The `support` column ranges 0.75–0.99, so the spread covers most of the LUT.
- **Branch-mean continuous coloring** (`08_color_branches_by_support.svg`) maps each internal branch through `cmap(mean(descendant tip values))`. Subtrees with no observed values keep the default color silently — different from the discrete monophyly path, which warns.
- **Circular layouts cover the full feature surface for clade highlights only** in v0.3. `.color_tips_by`, `.color_branches_by`, `.scale_bar`, and `.support_labels` on `.layout("circular")` raise `NotImplementedError` cleanly — natural follow-ups but not in v0.3 scope.

## Regenerating

From the repo root, with the development env set up per `README.md`:

```bash
python scripts/regen_assets.py
```

The script writes `assets/primates.svg` (the README screenshot) and every file in `assets/gallery/`. Bytes are deterministic — a clean run produces an empty `git diff` if no source changed.
